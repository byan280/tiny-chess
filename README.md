A strong chess engine in 4 KB of Python, built for the make.fun tiny-chess-01 bounty: negamax with alpha-beta, quiescence search, iterative deepening under a fixed node budget, a transposition table, killer-move ordering, MVV-LVA capture ordering, and a tuned material + piece-square evaluation. `main.py` is the entrypoint packed from the readable source with `makefun compress`; it speaks the competition environment protocol over HTTP.

## Run it

```sh
python3 -P -s main.py
```
